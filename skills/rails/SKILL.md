# 铁路 12306 车票查询

## 链路

12306 **没有开放平台，也没有官方 MCP**（官网明确写着"未授权其他网站或APP开展类似服务"）。本 skill 复用官网自己的查询链路，纯标准库实现，无 key：

```
GET /otn/leftTicket/init    -> JSESSIONID / BIGipServerotn / SF_cookie_2
GET /otn/leftTicket/queryZ  -> data.result[]（URL 编码的 | 分隔行，需 unquote）
```

- 脚本：`skills\rails\scripts\rail.py`
- 车站表缓存：`data\rails\stations.js`（首次自动拉取，约 200KB，之后本地读）
- 抓一次约 0.6 秒，无调用次数限制，**不花钱**

## 用法

```powershell
$py = "skills/rails/scripts/rail.py"

python $py stations 厦门                       # 查电报码（支持模糊）
python $py query 厦门北 杭州东 2026-11-05       # 余票
python $py query 厦门 北京 2026-11-05 --types G,D --limit 20
```

`--types` 过滤车次前缀：`G` 高铁、`D` 动车、`Z` 直达、`T` 特快、`K` 快速。`--limit 0` 看全部。

## 输出列

`车次 / 出发 / 到达 / 历时 / 二等 / 一等 / 商务 / 无座 / 状态`

- 余票是 `有`（充足）或数字（具体张数），`-` 表示不售卖或无此席别
- 状态 `可订` / `不可订`（对应接口 `canWebBuy`）

## 硬约束

1. **只查不买。** 12306 下单要登录态、实名乘客、验证码，脚本不碰这些。查完把车次丢给用户去 App/官网下单。
2. **日期窗口**：12306 一般只放 15 天内，超出会返回空或报错，先确认日期。
3. **站名要具体**：`厦门` 和 `厦门北` 是两个站，跨市高铁多从北站发，问清楚再查。
4. **同一车次可能出现多行**：12306 对不同开行方案/编组会返回多条同车次号记录，以出发时间为准，必要时按实际出发时间再确认。

## 已知坑

1. 必须先打 `/otn/leftTicket/init` 拿 cookie，直接打 `queryZ` 会返回「铁路客户服务中心」HTML 页面（HTTP 200 但内容不是 JSON）。
2. `data.result` 里每行是 **URL 编码** 的，不 `unquote` 会得到 `%2F` 乱码。
3. 字段顺序靠下标，官网改版会错位——解析异常时先打印原始行核对。
4. 高频请求会触发风控，出现返回 HTML/验证码就停，别重试刷。
5. 站名解析支持拼音简称（如 `xmb` → XKS），但中文站名更稳。
