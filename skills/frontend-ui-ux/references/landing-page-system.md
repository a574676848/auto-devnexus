# 高转化落地页系统 (Landing Page System)

落地页不是首页。首页服务多个意图，落地页只赢一个：

**一个主张 → 一个受众 → 一个主行动。**

本模块分两半：前半决定 **说什么、按什么顺序说**，后半决定 **页面如何被看见、如何被信任、如何上线**。视觉数值一律走 `visual-system-tokens.md`，动效编排走 `motion-and-interactions.md`。先做前半，再碰后半。

---

## 1. 需求采集 (Intake)

一次批量问齐，只问缺失项；不要一问一答拉长战线。

**目的**
- 唯一主行动是什么（试用、预约演示、购买、加入等待名单、下载）
- 提供的到底是什么，用户拿到手的是什么
- 什么算一次转化（点击、注册、付费）

**受众与情境**
- ICP 是谁，当前最想解决的问题是什么
- 前三大异议：他们今天为什么不转化
- 流量来源：广告、搜索、社交、邮件
- 落地时访客已经知道什么

**证明材料**
- 可用证据：客户 Logo、证言、数字、案例
- 截图、演示视频、产品 GIF
- 保障条款：试用、随时取消、退款

**约束**
- 品牌语气：口语还是专业
- 设计方向：极简编辑风、玩味 3D、玻璃拟态
- 移动端优先与否

采不到答案时的处理：给出合理假设，用一行文字声明假设，然后继续构建。**不得因此卡住交付。**

---

## 2. 页面结构 (Page Structure)

**首屏（必需）**
1. 主标题：结果 + 受众
2. 副标题：说明怎么做，并补足具体性
3. 主 CTA：动词 + 所得
4. 一条证明信号：Logo 条、关键数字、一条短证言
5. 主视觉：产品截图、演示视频，或强识别度插画

**中段（把道理讲完）**
6. 从问题到方案，一段讲清
7. 利益点 3 到 5 条，写结果不写功能
8. 三步说明怎么用
9. 社会证明：证言或一个完整案例

**底部（异议处理）**
10. FAQ 6 到 12 条
11. 风险反转：试用、随时取消、退款
12. 终版 CTA，与首屏完全一致

**标语揭示区**（强制，见第 10 节）放在中段论证里，通常在首屏之后或利益点之后，单独成段，不贴着首屏堆叠。

---

## 3. 版式选型 (Layout Selection)

只选一种，并说明理由。

| 类型 | 适用场景 |
| :--- | :--- |
| **A. 经典首屏 + 分区** | 产品靠一张首屏截图就能看懂，最常见 |
| **B. 长文叙事** | 需要教育市场、逐步消解怀疑 |
| **C. 极简转化页** | 高意图流量（定向邮件、老用户），或下载/等待名单这类短链路 |
| **D. 对比页** | 搜索意图含“X 对比 Y”“最佳方案”，通常与 SEO 页配套 |

---

## 4. 转化规则 (Conversion Rules)

- **讯息同源**：流量来自广告时，首屏标题要与广告文案同承诺、同语气、同视觉调性。
- **下一步唯一**：只留一个主 CTA，首屏严禁并置竞争性按钮。
- **利益先行**：功能是它做什么，利益是这对用户意味着什么。先写利益，再补证据。
- **具体化**：不写“节省时间、提升效率”，写“把每周报表从 4 小时压到 15 分钟”。
- **降低风险**：至少给一条保障：免费试用、免费版、无需信用卡、随时取消、退款。
- **异议成段**：异议要有独立区块，不做脚注。高摩擦产品把 FAQ 前移；证明要紧贴它支撑的那句主张。

---

## 5. 文案 (Copywriting)

**标题公式**
- `{结果}，不用{代价}`
- `为{受众}打造的{品类}`
- `{时间}内交付{成果}`

**副标题**：一到两句，说清它是什么、给谁用。

**CTA**：动词 + 所得。禁用“了解更多”“立即提交”。用“开始免费试用”“预约演示”“领取清单”。

**利益点子弹**：粗体写利益，破折号后接证据或细节。例：**迭代更快**，一次生成三个版式方案。

文案的排版纪律（连字符、孤字、大小写）见 `visual-system-tokens.md` 第 2 节，此处不重复。

---

## 6. 构建顺序 (Build Order)

逐段推进，一段一验证，禁止每次迭代重写整页：

1. 首屏
2. 利益点
3. 怎么用
4. 证明
5. FAQ
6. 终版 CTA

逐段构建的好处是控制得住，且每次 diff 可审查。

---

## 7. SEO 与 AEO

- **不收录**：纯广告投放页、强时效活动页。用 `noindex`，或放在不收录的路径下。
- **要收录**：常青主张页，且搜索意图与承诺一致。补齐 title、meta description，从首页与功能页做内链，FAQ 写成直白的问答对以适配 AEO，必要时补 FAQ schema。

---

## 8. 常见陷阱 (Pitfalls)

- 首屏堆多个 CTA
- 价值主张含糊："streamline""optimize"“赋能提效”
- 功能清单很长，一个结果都没有
- 证明埋在页脚
- 移动端布局破坏可读性
- 没有明确的下一步

---

## 9. 内容真实性与状态完整性

### 9.1 内容真实性 (Content Realism)

每一处示例内容都要像一个有真实用户的产品写出来的。

- **写真的文案**：不用拉丁占位、不用“标题写这里”。按产品口吻写完整句子。
- **人**：证言与团队成员给完整姓名，符合产品受众与地区；同一张脸不得复用到两个人。
- **品牌**：客户名要像该行业的公司。物流工具的客户像物流公司，不像通用科技创业公司。
- **数字**：避免可疑的整数。价格像真实定价，指标带小数或非整尾数，日期在同组内要有差异。
- **禁用填充词**：revolutionize、supercharge、cutting edge、effortless、transform your workflow、take it to the next level、harness the power、world class，以及中文对应的颠覆、赋能、极致、一站式、无缝、下一代。
- **系统消息**：确认要克制且具体（“发票已发送至 Dana”）；错误要说清哪一步失败、下一步做什么（“上传失败，文件超过 20 MB”）。不用感叹号，不用卖萌语气词。

### 9.2 状态矩阵 (States)

每个可交互元素必须交齐状态：

- **Hover**：底色位移、轻微缩放或位移
- **Active**：`scale(0.98)` 或 `translateY(1px)`，给物理反馈
- **Focus**：可见焦点环，无障碍要求，不是可选项
- **Loading**：贴合真实布局的骨架屏，禁止圆形转圈
- **Empty**：成形的“开始使用”视图，禁止空白面板
- **Error**：内联且具体，禁用 `window.alert()`

无死链。指向 `#` 的按钮要么接上真实地址，要么呈现为禁用态。当前页必须在导航中高亮。

### 9.3 上线必备清单 (Ship Requirements)

这些项最容易被忘，也最容易让页面显得没做完：

- [ ] 页脚的法务链接（隐私政策、服务条款）
- [ ] 定制的品牌化 404
- [ ] 前端表单校验（邮箱格式、必填项）
- [ ] 键盘用户的“跳到正文”链接
- [ ] 按司法辖区要求的 Cookie 同意
- [ ] 品牌 favicon
- [ ] `<title>`、meta description、`og:image`、社交分享标签
- [ ] 每张有意义图片的 alt 文本
- [ ] 语义标签：`<nav>` / `<main>` / `<article>` / `<aside>` / `<section>`
- [ ] 每个页面都有回退路径

## 10. 标语揭示区（强制区块）

每个落地页都必须有 **一个大字号标语段**，独立成段陈述核心利益，不附属于首屏。

**文案**
- 至少两行。
- 用第 5 节的语气写利益或主张，不是通用的“我们的优势”式小标题。

**排版**
- 字号在 `text-4xl` 到 `text-6xl` 之间，按行数取阶（见 `visual-system-tokens.md` 第 3 节）。
- 宽度与首屏同限，按语义断行。

**动效**
- 初始为弱化态：约为主文字色的 25% 到 35% 透明度。
- 滚动进入视口时，按阅读顺序 **逐词** 从弱化态过渡到实色。
- 逐个跨过触发线激活，禁止整块一次性翻转。过渡使用基准曲线（见 `motion-and-interactions.md`），禁用线性淡入。
- 用逐词 `IntersectionObserver` 实现，或单个监听器经 `requestAnimationFrame` 节流。**严禁 `window.addEventListener('scroll')`。**

```tsx
"use client";
import { useEffect, useRef } from "react";

export function TaglineReveal({ text }: { text: string }) {
  const ref = useRef<HTMLParagraphElement>(null);
  const words = text.split(" ");

  useEffect(() => {
    const root = ref.current;
    if (!root) return;
    const nodes = Array.from(root.querySelectorAll<HTMLElement>("[data-word]"));
    const io = new IntersectionObserver(
      (entries) => {
        for (const entry of entries) {
          if (entry.isIntersecting) {
            (entry.target as HTMLElement).dataset.on = "true";
            io.unobserve(entry.target);
          }
        }
      },
      { threshold: 0.6, rootMargin: "0px 0px -12% 0px" },
    );
    nodes.forEach((node) => io.observe(node));
    return () => io.disconnect();
  }, []);

  return (
    <p ref={ref} className="max-w-[680px] text-4xl md:text-6xl leading-[1.05] tracking-tight text-wrap-balance">
      {words.map((word, i) => (
        <span
          key={`${word}-${i}`}
          data-word
          className="inline-block opacity-30 transition-[opacity,color] duration-500 ease-[cubic-bezier(0.22,1,0.36,1)] data-[on=true]:opacity-100"
        >
          {word}
          {i < words.length - 1 ? "\u00a0" : ""}
        </span>
      ))}
    </p>
  );
}
```

## 11. 导航与滚动揭示

- **静息态导航**：一条脱离顶边的浮动条，居中并按内容宽度收窄，不用贴边通栏。半透明底加背景模糊，让页面内容隐约透出。间距走刻度表，圆角走嵌套公式。
- **菜单开关**：开合图标在同一图标内形变过渡，禁止瞬间替换。用白名单图标库，或自绘线条，过渡走基准曲线。
- **移动端菜单**：展开为整屏面板，不是小下拉。面板底色用主题基面高不透明度 + 强模糊。
- **链接入场**：按阅读顺序逐条从下方 24px 处上浮并淡入，每条比前一条晚 60ms，整段序列上限 400ms，长菜单也不会拖沓。
- **滚动揭示**：区块进入视口时上浮 32px 并从 0 淡入到全不透明，600 到 800ms，基准曲线。每个区块只播一次，向上滚回不重播。
- **触发方式**：`IntersectionObserver` 或 Framer Motion 的 `whileInView`。严禁挂在未节流的滚动监听上。
- **基准曲线**：`ease-[cubic-bezier(0.22,1,0.36,1)]`，布局与位移用 `duration-500`；颜色与透明度 hover 可用 `duration-300`，不得短于 200ms。
- **降级**：`prefers-reduced-motion` 下位移改为纯透明度变化。

## 12. 交付输出格式 (Output Format)

从零生成落地页时，先按序给出以下内容，再写代码：

1. **页面大纲**：区块与顺序
2. **首屏文案**：标题、副标、CTA、证明行
3. **利益点**：3 到 5 条结果导向的子弹
4. **怎么用**：三步
5. **FAQ**：6 到 12 问与答
6. **SEO / AEO**：收录或不收录的建议，收录时给 title 与 meta
7. **版式建议**：A / B / C / D 之一，并给理由

随后按第 6 节的顺序逐段构建。

## 13. 交付前自检

**策略**
- [ ] 一个主张、一个受众、一个主行动
- [ ] 首屏无竞争性 CTA
- [ ] 用具体数字替代含糊动词
- [ ] 至少一条风险反转
- [ ] 证明紧贴它所支撑的主张
- [ ] 版式类型是主动选定的

**视觉**
- [ ] 单一合资格字面，无斜体，无超粗字重
- [ ] 零句内连字符，零孤字
- [ ] 字号全部落在字阶表
- [ ] 间距全部落在刻度表
- [ ] 嵌套圆角按公式推导
- [ ] 零单边卡片边框，零背景渐变
- [ ] 首屏标题与副标限宽 680px，断行落在语义处
- [ ] 图标来自白名单库
- [ ] 过渡全部走基准曲线，揭示用 IntersectionObserver
- [ ] 标语揭示区在场，至少两行，滚动时逐词点亮

**内容与上线**
- [ ] 真实文案、可信人名与数字，零禁用填充词
- [ ] hover / active / focus / loading / empty / error 状态齐备
- [ ] 零死链，当前导航项已标出
- [ ] 404、法务链接、表单校验、favicon、meta、alt 全部到位
