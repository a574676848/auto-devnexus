# 视觉 Token 硬刻度规范 (Visual System Tokens)

> 本模块解决“数值靠临时发明”的通病。任何字号、间距、圆角、底色与图标都必须经由本文档解析，不得即兴给值。
> 与框架默认值冲突时以本文档为准；与长官显式指令冲突时以指令为准，但必须同时说明偏离代价。

---

## 1. 字体白名单与禁令

| 决策项 | 规则 |
| :--- | :--- |
| 推荐使用 | `Geist` / `Manrope` / `Poppins` / `DM Sans` / `Satoshi` / `Plus Jakarta Sans`，等宽另行使用 `Geist Mono` / `JetBrains Mono` |
| 严禁使用 | `Inter` / `Roboto` / `Arial` / `Open Sans` / `Helvetica`（AI 默认脸，一眼廉价） |
| 字面数量 | 单站点锁定 **一个主字面**。仅当代码、数值、数据面板在功能上确需等宽时，才允许叠加 Mono |
| 字重 | 允许到 `semibold` / `bold`，**严禁 900 与 black** |
| 斜体 | 界面内 **严禁斜体**（标题、正文、标签、按钮全部禁用） |

## 2. 文案排版纪律

- **句内连字符禁令**：正文、标题、标签内部不得用 `-` 连接词句；重写短语，不要硬连。与全局破折号禁令叠加执行。
- **孤字禁令**：任何一行不得只剩一个词。标题加 `text-wrap: balance`，正文加 `text-wrap: pretty`。
- **句子式大小写**：标题与按钮统一 Sentence case，不用每个词首字母大写的营销腔。
- **绝对填充词禁令**：不用“颠覆”“赋能”“一站式”“极致”“无缝”“下一代”“重新定义”，直说做什么。

## 3. 字阶表（唯一合法刻度）

非标尺寸一律 **向下吸附** 到最近一级，并连带使用该级自带行高。严禁 `text-[19px]`、`font-size: 22px`、`1.4rem` 这类任意值。

| 类名 | 字号 | 行高 |
| :--- | :--- | :--- |
| `text-xs` | 12px（0.75rem） | 16px |
| `text-sm` | 14px（0.875rem） | 20px |
| `text-base` | 16px（1rem） | 24px |
| `text-lg` | 18px（1.125rem） | 28px |
| `text-xl` | 20px（1.25rem） | 28px |
| `text-2xl` | 24px（1.5rem） | 32px |
| `text-3xl` | 30px（1.875rem） | 36px |
| `text-4xl` | 36px（2.25rem） | 40px |
| `text-5xl` | 48px（3rem） | 1 |
| `text-6xl` | 60px（3.75rem） | 1 |
| `text-7xl` | 72px（4.5rem） | 1 |
| `text-8xl` | 96px（6rem） | 1 |
| `text-9xl` | 128px（8rem） | 1 |

- **行高与字距只在该级给出的范围内微调**，不得另行覆盖为自造行高，避免“吸附”与“自定义”两套规则互相打架。
- **按钮字号**：主按钮 `text-base` + `semibold`；页头次级按钮 `text-sm` + `semibold`。
- **字阶降级**：移动端可在同一阶梯上整体下移 1 到 2 级，但每一级仍必须落在表内。

## 4. 间距刻度表（唯一合法刻度）

表外的值一律不准出现，表内相邻刻度之间不插值。

| Token | 值 |
| :--- | :--- |
| `Spacing-0` | 0 |
| `Spacing-25` | 2px |
| `Spacing-50` | 4px |
| `Spacing-75` | 8px |
| `Spacing-100` | 12px |
| `Spacing-200` | 16px |
| `Spacing-300` | 24px |
| `Spacing-400` | 32px |
| `Spacing-500` | 40px |
| `Spacing-600` | 48px |
| `Spacing-700` | 64px |
| `Spacing-800` | 80px |
| `Spacing-900` | 96px |

- **主按钮内边距**：纵向 8px，横向 12px（`py-2 px-3`）。
- **分节节奏**：区块纵向留白只取 `Spacing-700` / `800` / `900`，同一层级区块全站同值。
- **密度切换**：高密数据面板可整体下移到 `Spacing-300` 分节，但单个间距仍须命中表格。

## 5. 圆角与嵌套公式

- 只使用 Tailwind 圆角阶梯，全站圆角逻辑保持数学统一（同一语义元素全站同圆角）。
- **嵌套圆角公式**：内层形状被外层包裹，且两者间距 `< 32px` 时，`内圆角 = 外圆角 − 间距`；计算结果 `≤ 2px` 时改用直角或保持原值。
- 示例：外层 `rounded-2xl`（16px）内含 8px 内边距，内层取 `rounded-lg`（8px）。
- 与「双层嵌套倒角」完全同源：外壳 `rounded-[2rem]`（32px）配 `p-1.5`（6px）时，内层取 `rounded-[calc(2rem-0.375rem)]`（26px），即公式的同一解。

## 6. 边框、背景与暗色底

- **单边边框禁令**：卡片要么四边全有描边，要么完全无描边，不得只留一条下划线假装分隔。
- **背景渐变禁令**：背景一律纯色平铺。全文档唯一例外是第 7 节的英雄区标题文字渐变。
- **暗色底白名单**：`#0A0A0A` / `#181818` / `#1F1F1F` / `#272727` / `#313131` / `#131209`。
  - 上游规范允许 `#000000`；本仓库基线仍从 `#0A0A0A` 起步，纯黑只在 OLED 场景由长官显式点名时使用。
- **明色底白名单**：骨白 `#F7F6F3` / 未漂白纸基 `#F4F4F0` / 暖奶油 `#FDFBF7`。严禁大面积纯白无层次平铺。
- **对比度**：文字与交互元素一律过 WCAG AA（4.5:1），禁用白底白字与幽灵色。

## 7. 英雄区排版

- **标题文字渐变**（全站唯一允许的渐变，且只作用于文字，不作用于背景）：暗色主题 `#FFFFFF → #9B9B9B`，明色主题 `#000000 → #666666`，方向从左到右。
- **宽度上限**：标题与副标题统一 `max-w-[680px]`；超宽就在语义停顿处断行，严禁把短语劈成两半。
- **行数上限**：桌面端主标题 1 到 3 行，首屏 CTA 无需滚动即可见。
- **视口保护**：容器用 `min-h-[100dvh]`，顶部 padding 上限 `pt-24`，内容不得漂浮在视口中线。

## 8. 图标系统

- 白名单：`Phosphor` / `Solar` / `Iconamoon` / `Lucide` / `Heroicons`。
- 黑名单：`Material Icons` / `Material Symbols`（默认脸、笔画僵硬）。
- 同页只准一套图标库，线宽（1.5 或 2）与端点（圆头或平头）统一。
- 尺寸只取 16 / 20 / 24 三档，并落在间距刻度上；图标与文字基线对齐，不用负 margin 硬拽。

## 9. 落地自检

- [ ] 全站只有一个主字面，无斜体、无 900 字重、无 Inter 类默认脸？
- [ ] 每个字号都能在字阶表找到对应类名，零任意值？
- [ ] 每个间距都能在刻度表找到对应值，零插值？
- [ ] 嵌套圆角是否按公式推导，而非目测？
- [ ] 是否零单边边框、零背景渐变（英雄区标题文字除外）？
- [ ] 暗色底是否落在白名单内，对比度是否过 AA？
- [ ] 图标库是否唯一，线宽尺寸是否统一？
